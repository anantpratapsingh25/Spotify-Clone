🎵 Spotify Clone
A fully responsive Spotify Clone built with modern web technologies that mimics the core features and sleek UI of the official Spotify web app. This project is designed for learning purposes, focusing on frontend development, responsive design, and integrating media playback functionality.

🚀 Features
🎧 Play, pause, skip tracks

🔊 Real-time audio controls (volume, progress)

🖼️ Dynamic UI updates based on selected track

📱 Responsive design for desktop and mobile

🌙 Dark-themed interface like the real Spotify

🎵 Playlist and album views

🛠️ Tech Stack
HTML / CSS / JavaScript

React.js (or Vanilla JS, depending on your stack)

Tailwind CSS or CSS Modules

Optional: Spotify Web API (for real song data)
